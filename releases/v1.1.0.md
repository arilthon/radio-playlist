## Novidades

- Edição de rádios pelo painel, incluindo a rádio principal, com preservação dos dados.
- Captura contínua durante falhas de autorização ou acesso ao serviço musical.
- Retomada das rádios iniciadas pelo painel após reiniciar o contêiner.
- Tentativas por música com espera progressiva e encaminhamento para revisão.
- Correção de artistas separados por `/`, nomes repetidos e créditos `(feat. ...)` nos títulos.

## Atualização

Faça backup do volume antes de atualizar. O banco recebe novas colunas automaticamente.

Defina no `.env`:

```dotenv
RADIO_IMAGE=ghcr.io/arilthon/radio-playlist:1.1.0
```

Execute na pasta do Compose:

```bash
docker compose pull radio
docker compose up -d --no-build radio
```

Na primeira execução desta versão, inicie as rádios pelo painel para registrar a retomada automática. Reprocesse as músicas anteriormente marcadas como incertas para aplicar a correção dos artistas.

Rádios com histórico permitem editar nome e URL. Para trocar o serviço ou a playlist dessas rádios, cadastre uma nova rádio.
